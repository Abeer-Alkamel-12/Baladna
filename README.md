A Syrian Tourism Platform

🔵 About the Project

Baladna is a web-based tourism platform designed to help users explore tourist destinations across Syria, discover available trips, and manage their travel bookings through an intuitive digital experience.

The platform aims to support and promote tourism in Syria by bringing tourist destinations and travel services together in one digital platform. It provides users with an easier way to discover places, explore trips, and manage their travel bookings.

✨ Key Features

- Explore tourist destinations across Syria.
- Browse available trips and view trip details.
- Search and filter destinations.
- User registration and authentication.
- Manage personal profiles.
- Manage travel bookings.
- Save favorite destinations.
- Submit reviews and ratings.
- Contact and support services.
